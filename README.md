# ASCII Video Player

Превращает любое MP4-видео в ASCII-анимацию прямо в терминале!  
Вдохновлено культовым [Bad Apple!!](https://www.youtube.com/watch?v=FtutLA63Cp8), но работает с **любым видео**.

---

## Быстрый старт

1. Установите зависимости:
     fluent-ffmpeg,
     jimp,
     node

> **А так же установите на свой ПК ffmpeg:** winget install ffmpeg

---

## Автоматический размер под окно терминала

Размер конвертированного ASCII-видео **автоматически определяется по текущему размеру окна командной строки (CMD/терминала)**

1. **Чтобы видео заняло весь экран**
    Разверните окно терминала на полный размер

2. **Запустите скрипт** - cкрипт сам подгонит видео под доступную ширину и высоту
    *node main.js*
